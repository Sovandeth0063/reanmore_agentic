# Scenario evidence

These JSON files are generated by `scripts/run_scenario.py`; do not edit them
by hand. They contain the student lines, tutor replies, per-stage latency, the
summary, and the four milestones. They contain no audio, image bytes, prompts,
or keys.

| File | Mode | What is real |
| --- | --- | --- |
| `2026-11-13-ip3_homework2-text.json` | text | **Demo evidence.** The in-process controller, lesson, calculator, and tutor state machine with the checked-in 12-item worksheet fixture and the deterministic template renderer. No vision call and no speech. |
| `2026-11-13-ip3_homework2-text-hosted-renderer-experimental.json` | text | **Experimental.** The same run with the hosted `llm` renderer. It shows the warmer wording, but one hosted call took ~64 s and the global leak detector false-positived on printed operands and duplicate answers; it is not demo evidence. |
| `2026-11-13-ip3_homework2-voice-voxpocket-diagnostic.json` | voice | **Diagnostic.** The live backend and VoxPocket service with synthesized student lines. VoxPocket English short-word/math quality and latency made the synthetic voice path unsuitable for the demo; the demo uses browser `SpeechSynthesis` and the text report above. |

Regenerate the demo text report from the repository root:

```bash
py -3.10 scripts/run_scenario.py --mode text \
  --out docs/scenarios/results/2026-11-13-ip3_homework2-text.json
```

The voice diagnostic requires the backend on `http://127.0.0.1:8000` and the
TTS service on `http://127.0.0.1:8001`; warm the voice before the run. The
runner checks both services and never starts them. `--audio-dir` is optional,
must be outside the repository, and no audio is committed here. The demo
dashboard uses browser `SpeechSynthesis` by default (`VITE_TTS=browser`), so
the voice service is not part of the demo path.
